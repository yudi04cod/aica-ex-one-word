One word for make.fun's "Describe Your Ex in One Word": **Expired** —
the verdict you give a carton of milk at the back of the fridge. Past
its date, no longer fit for use, and nobody is surprised it had to go.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the word
(letters only, 1 to 111 characters, a single word), and writes the
same 7 bytes on every run.
